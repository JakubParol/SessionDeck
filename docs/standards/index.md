# Standards Index

SessionDeck standards are adapted from the CrackerAi workspace standards and narrowed for this project: a local-first macOS session viewer for AI-agent transcripts.

## Mandatory Reads

Any agent working in this repository MUST read the relevant standards before changing files.

| Document | When |
|---|---|
| [Coding Standards](coding-standards.md) | Before writing, modifying, or reviewing any code |
| [macOS App Standards](macos-app-standards.md) | Before any macOS/UI/app-shell work |
| [Testing Standards](testing-standards.md) | Before writing or modifying tests |
| [Planning Standards](planning-standards.md) | Before drafting epics, features, stories, or Jira issues |
| [Documentation Standard](documentation.md) | Before creating or modifying documentation |

## Override Rule

Project-specific instructions in `AGENTS.md` override these standards only when they are more specific. If a conflict is unclear, stop and ask Kuba before proceeding.
